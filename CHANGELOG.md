# Changelog

## 0.1.0 — 2026-10-30

Initial public release, delivered as a GitHub Flatpak and through Spaced Bazaar.

- Control supported lighting with OpenRGB and liquidctl, select all devices,
  adjust brightness and save presets.
- Enable hardware access with host authentication and refresh without restarting.
- Control Galahad II LCD lighting and display images, a clock or CPU temperature
  in Fahrenheit, with diagnostic logs and guarded firmware tooling.
- Bundle the LCD encoder and pinned dependencies for the Linux Flatpak.

Hardware support depends on the upstream drivers and enabled device permissions.
